## 🏮 Nov 20 – Dec 4: 10-Word Long `/ī/` Phonics & Typo Check Matrix

> **Teacher Sanity-Check Note:** Mrs. Ulrich's Nov. 20 email accidentally typed `"byself"` inside the `'y'`-as-long-`/ī/` pair alongside `reply` (a `b`/`m` keyboard slip). This suite teaches the true phonics word **`myself`** (`my | self`) cleanly across all student-facing games, audio, slides, and paper mats!

| Lantern Group | Target Words | Syllable & Slow-Down Coaching Cue |
| :--- | :--- | :--- |
| **Open Syllable `'i'`** | **silent**, **spider** | `si \| lent`, `spi \| der` — Open first syllable ends in `i`, so `i` says `/ī/`! (`spider` adds Bossy-R `er` and is an 8-legged arachnid!) |
| **Magic Silent-`e` `'i_e'`** | **pinecone**, **bedtime** | `pine \| cone`, `bed \| time` — Compound words! Carryover **`c` vs. `k`**: `c` before `o` in `cone`! |
| **Open `'y'` as Long `/ī/`** | **myself**, **reply** | `my \| self`, `re \| ply` — Open `my` and ending `y` say long `/ī/`! *(Corrects `byself` email typo)* |
| **3-Letter Team `'igh'`** | **right**, **highlight** | Silent `gh`! Three letters (`i-g-h`) team up for ONE `/ī/` sound. `high \| light` packs DOUBLE `'igh'`! |
| **Vowel Team `'ie'` + `-ed`** | **tied**, **cried** | `tie + d`, `cry → i + ed` — Carryover **`c`** before `r` in `cried`! |
